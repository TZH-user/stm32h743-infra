# DAC1 到 AD9226 校准回环实机测试

## 结论

- **有依据：回环链路通过。** PC6/PC7 双高后，PA4 DAC 标称输出从 0 V 逐步增加，AD9226 均值连续反向变化；两次独立扫描结果一致。
- **有依据：安全保护通过。** 两次均在传递平台出现后自动停止，结束时 PC6/PC7 双低、DAC DOR1 为 0、AD9226 停止，`CFSR/HFSR=0`。
- **有依据：当前不能完成全量拟合。** 标称约 1.10 V 后传递曲线稳定在约 1618 code，且远离 ADC 的 0/4095 码限。这是模拟链路平台，不是 ADC 数字满码削顶；1.10 V 以上数据不得用于线性拟合。
- **经验判断：** 平台可能来自模拟前端钳位、继电器接线落点、PA4 DAC 受载或其他模拟限制，需要示波器/万用表测 PA4 与 AD9226 输入节点才能区分。
- **有依据：8 Mbps 连续串口控制不通过。** MCU 侧 DMA 保持运行且无 restart failure，但同一 COM3 打开周期内后续命令会间歇性完全不到达；单命令独立打开端口较可靠。
- **有依据：串口主动 STOP 未通过。** 五次有界 `CAL STOP` 尝试没有收到成功确认，部分命令被解析为损坏格式；本轮依赖自动平台保护安全收尾。

## 测试条件

- 工程：`F:\STM32\stm32project\VSCodeCMAKEProject\signal_separation`
- MCU：STM32H7xx Rev V，Device ID `0x450`
- 探针：STLINK-V3MODS，SN `002E00443234511337333934`
- 串口：USART1 / COM3 / 8,000,000 baud / 8N1
- 继电器：PC6/P2-18 与 PC7/P2-16，高高为 DAC1 回环，低低为正常链路
- 用户给出的模拟容限假设：`±5 V`
- 实际 DAC 扫描：名义 `0..3.0 V`，每步 `50 mV`，驻留 `25 ms`
- 每点采样：AD9226，1 MHz，4096 samples
- 自动停止：ADC 码限贴边、无响应、明显反向突变、连续传递平台、IO 错误

`0..1.05 V` 区间大致每增加 50 mV，ADC 均值下降约 20 code；`1.10 V` 后增量接近零。该重复性支持平台为真实链路现象，而不是单次随机噪声。

## 软件能力

- 校准页进入后暂停 MainTask、PhaseLockTask 和无关 AD/DA，持有资源独占。
- ADC/DAC/继电器/QSPI Port 均已注册，START 门禁可用。
- 内部 Worker 非阻塞分步推进，异常路径统一执行 ADC stop、DAC 归零/停止、继电器双低。
- 每个点写入 QSPI 会话日志；本轮产生测试会话记录，未发起日志清理或烧录器侧 QSPI 擦除。
- `CAL STATUS` 可返回当前点、停止原因、继电器 ODR、DAC DOR1 和 ADC running。
- 代码语义上，校准页 STOP 结束会话并停留在 REVIEW，HOME/BACK 才退出页面并释放独占；但本轮串口模拟 STOP 未通过实机验收。

## 尚未证明

1. 没有外部精密电压参考，因此不能分别辨识 DAC 增益/零偏与 ADC 增益/零偏；当前只能测组合传递函数。
2. 没有测量 PA4 实际电压，日志中的 mV 是按 3.3 V VDDA 的标称 DAC code 换算。
3. 没有测量继电器触点电阻、抖动时间或 AD9226 差分输入两端电压。
4. 没有验证负半轴，因为 STM32 片内 DAC 只能输出非负电压。
5. 平台原因未定位前，不生成、不确认、不立即应用校准 Profile。
6. 8 Mbps VCP 修复前，不能把串口 STOP 当作唯一安全手段；板端自动停止条件必须始终保留。

## 建议的硬件复核

在下一次扫描时同时测量三个节点：PA4、继电器后节点、AD9226 驱动器输入/输出。重点记录 DAC 标称 1.00 V、1.10 V、1.20 V 三点：若 PA4 继续上升而 ADC 节点不变，问题在继电器后模拟前端；若 PA4 本身不再上升，优先检查 PA4 负载和 DAC 输出缓冲能力。
