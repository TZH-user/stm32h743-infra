# 校准安全冒烟测试

## 测试信息

- 时间：2026-07-26 00:43 +08:00
- 工程：`F:\STM32\stm32project\VSCodeCMAKEProject\signal_separation`
- 固件：`build\Debug\signal_separation.hex`
- 探针：STLINK-V3MODS，SN `002E00443234511337333934`
- 目标：STM32H7xx Rev V，Device ID `0x450`，内部 Flash 2 MiB
- 目标电压：连接时 3.28 V，烧录时 3.29 V

## 安全边界

- 只烧录当前 Debug HEX 并启动，不执行 Mass Erase，不修改 Option Bytes。
- 不启动校准 Session，不驱动 PA4 DAC，不将 PC6/PC7 拉高。
- 不擦除或写入外部 QSPI；仅验证启动初始化后的 `qspi_ready` 状态。
- 校准进入由 GDB 调用公开服务接口完成，不模拟触摸操作。

## 已验证结果

1. Debug configure/build 成功，ELF/HEX/BIN/MAP 已存在且 Ninja 报告无待构建项。
2. STM32CubeProgrammer 对内部 Flash 扇区 0-6 完成下载与校验，随后复位运行成功。
3. 初始快照为 `IDLE`、`exclusive=false`、`can_start=false`、`qspi_ready=true`。
4. 初始 `GPIOC->ODR=0`，PC6/PC7 均为低电平。
5. 调用 `AppCalibrationService_RequestEnter(INTERNAL, DAC1_TO_ADC)` 返回 `true`。
6. 服务进入 `READY` 后：
   - `error=APP_CALIBRATION_ERROR_ADC_NOT_CONFIGURED`
   - `exclusive=true`
   - `can_start=false`
   - `qspi_ready=true`
   - MainTask 不在运行，PhaseLockTask 不在运行
   - `GPIOC->ODR=0`，PC6/PC7 仍为低电平
7. 调用 `AppCalibrationService_RequestExit()` 返回 `true`；随后恢复 `IDLE`、`exclusive=false`，PC6/PC7 仍为低电平。
8. 故障寄存器：`CFSR=0`、`HFSR=0`、`MMFAR=0`、`BFAR=0`、`AFSR=0`；未发现 CPU fault。

## 未覆盖项

- 未通过触摸界面实际点击 Calibration/HOME，因此本报告不作为触摸导航视觉验收。
- COM3 以 10 Mbaud 有界读取 4 秒得到 0 字节；当前固件在该窗口内没有输出，不据此判定启动失败。
- 未用万用表或示波器测量 P2-18/P2-16 的实际引脚电压；`GPIOC->ODR=0` 是 MCU 寄存器级证据。
- 未验证 QSPI 擦除、写入、掉电恢复和 CRC 恢复。
- ADC/DAC Port 尚未配置，真实 PA4 到 AD9226 回环仍被硬门禁阻止。

## 结论

校准安全状态机冒烟测试通过：固件可启动、QSPI 初始化就绪、进入校准后正常任务被停止、START 保持硬禁用、继电器输出保持双低，退出后独占正确释放且无 CPU fault。该结果不等同于真实模拟回环通过。
