## 工具

- `_tools\projclone.py` + proj-clone 技能:克隆/派生/归档,dry-run 先行,Templates 只能作 src。
- `_tools\template_selftest.py`:模板冒烟自检(关键文件 + configure + build + EN 残留中文检查);改模板后必跑。
- `ProjNew工具_策划案.md`:派生+裁剪+Function 模块选装一条龙(待实施)。
- 硬件/算法模块库:`F:\STM32\stm32project\Function\`(接入方法见各模板 CMakeLists 注释组与 Function 根索引)。

## 上游同步(signal_separation → 模板)

上游仍在活跃演进。同步纪律:

1. 上游有实质改动(功能/修复)→ 用 proj-clone 克隆出 `_candidate_<日期>` 临时目录;
2. 与现模板 diff,决定整体替换或摘取合并;
3. CN 更新后,EN 重新克隆 + 按 `H743_Instrument_EN\translation_map.md` 重刷翻译 + 复核槽宽缩写;
4. 更新本表版本列,跑 template_selftest.py,git commit。

## 模板↔Function 回流

项目里改好的驱动,结项时 diff 回流 `Function\Hardware`;模板本体的修复(如 BSP bug)同时回流 Function 与另一语言版模板,避免三处漂移。
