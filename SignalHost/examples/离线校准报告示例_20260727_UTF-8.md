# SignalHost 离线校准报告示例（2026-07-27，UTF-8）

## 结论

- `HOST_UI_TEST_PASS`：本报告示例来自 serial fake 数据，可复现 parser、拟合与导出流程。
- `PROTOCOL_STATIC_PASS`：本任务使用的字段和 CRC 规则按固件真源静态核对。
- `PROTOCOL_BASELINE_DRIFT`：若当前未提交固件源码出现未评审的 UNDO/EXPORT，报告
  必须单独标记，不能由上位机抢先启用。
- `HARDWARE_PENDING`：未连接 COM3、仪器或 ST-Link；未执行真实 CAL/QSPI、烧录或复位。

## 数据与模型

- 来源：`SERIAL_FAKE_V1`
- 原始点顺序：`-1000 mV → 0 mV → 1000 mV`
- ADC 模型：`code = 800 * voltage + 100`
- R²：`1.0`
- 最大绝对残差：`0 code`
- 点数：`3`
- Profile sequence：`NOT_PROVIDED_BY_SERIAL_PROTOCOL`

## 生命周期边界

`CONFIRM` 与 `APPLY` 是独立动作。示例不代表真实 QSPI 持久化、掉电保持或校准精度通过；串口没有 `CAL UNDO`，GUI 只显示禁用提示。
